Rules:
- One question per missing field, in the order given. Never more than the allowed number.
- Each question is short, specific to this report, and answerable in one sentence.
- Do not ask for anything already stated in the report.
- Set wants_screenshot to true only if the bug is visual (layout, rendering, a wrong screen, an error dialog).
- Return a single JSON object matching the schema. No prose before or after it.
